## Project Setup

1. Install Node.js.
2. Open this project folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL shown in the terminal.

## Features
- Home page with doctor and appointment counts
- Doctor list with name search and specialization filter
- Dynamic doctor details page
- Book appointment action
- My Appointments page
- Navigation using React Router

## Dataset
The local doctor dataset is stored in `src/data/doctors.js`.
